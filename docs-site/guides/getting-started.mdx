## Requirements

- A working [ComfyUI](https://github.com/comfyanonymous/ComfyUI) install with a GPU that can run the image model you pick.
- The model files for the features you want to use. See [Models](/guides/models). Qwen Image 2.1 alone is enough for generation, quick edit, edit text and expand.

## Install

<Steps>
  <Step title="Clone into custom_nodes">
    ```bash
    cd ComfyUI/custom_nodes
    git clone https://github.com/jtydhr88/ComfyArt
    ```
  </Step>
  <Step title="Install the Python requirements">
    Use the same Python environment that runs ComfyUI. This adds `pypdfium2` (PDF uploads) and `rapidocr` (text recognition for [Edit Elements](/guides/elements-mockups)).

    ```bash
    pip install -r ComfyArt/requirements.txt
    ```
  </Step>
  <Step title="Restart ComfyUI and open ComfyArt">
    Click **ComfyArt** in ComfyUI's top bar, or open [http://127.0.0.1:8188/comfyart/](http://127.0.0.1:8188/comfyart/) in your browser. You land on the [home page](/guides/home); click **New Project** for an empty canvas.

    <Frame>
      <img src="/images/comfyui-topbar.webp" alt="The ComfyArt button in ComfyUI's top bar" />
    </Frame>
  </Step>
</Steps>

The button also shows in Comfy Desktop, where there is no address bar to type the URL. To go back, use **Back to ComfyUI** in the home rail or in a project's logo menu.

The built page ships in `dist/`, so you do not need Node.js to use ComfyArt. Only if you change the frontend source in `src/`, rebuild it with `npm install && npm run build`.

## Your first image

<Frame>
  <img src="/images/canvas.webp" alt="The ComfyArt canvas with a selected image and its toolbar" />
</Frame>

1. Click **Image Generation** in the bottom bar. A generator card appears on the canvas with a prompt box under it.
2. Describe the image. Put any text that should appear in the image in quotes, for example `the title "SUMMER DRINKS"`.
3. Pick a size, ratio and count, then press the arrow button. A progress ring runs around the card while ComfyUI works.
4. Select the result to open the image toolbar: quick edit, upscale, remove background, eraser, and many more tools under **⋯**.

## Projects and language

- Each project is a URL: `/comfyart/?project=<id>`, saved in ComfyArt's SQLite database (`user/__comfyart/data.db`) with snapshot history you can restore. See [Home and projects](/guides/home).
- The interface starts in ComfyUI's language (English or Chinese); switch it any time from the settings menu.
