---

所有视频生成都用 MiniMax H3（见[模型](/zh/guides/models)）。剪辑和放大只用 ComfyUI 核心节点。每段视频都带有和画面一起生成的声音。

## 动态图片

选中一张图，点 **动态图片**。描述想要的动作，或者留空，用默认的轻微动作。

- **首尾循环** 默认打开：首帧同时用作尾帧，播放时无缝循环。
- 结果是一张保持原比例的动图。

## 生成视频

把生成器或对话模式切到 **视频**，再选一种模式：

| 模式 | 作用 |
|---|---|
| **首尾帧** | 只用文字，或者从首帧开始，可选再指定尾帧。 |
| **参考生视频** | 最多 9 张图、3 段视频和 3 段音频：角色、产品和场景，要模仿的运镜或动作，声音或音色。提示词里分别写 `<Picture 1>`、`<Video 1>`、`<Audio 1>`，每种按添加顺序编号，并说明每个参考要做什么。视频会跟着这些参考走，而不是从固定的一帧开始。 |
| **动作控制** | 一张 **角色** 图和一段 **动作视频**。ComfyArt 从动作视频的每一帧提取人体姿态，角色会照着做出同样的动作。选动作视频时，比例和最长可用时长会自动跟着视频设置。 |
| **对口型** | 一张 **人像** 和一段 **语音**。语音就是视频的声音，人物的嘴型跟着说，视频时长等于语音长度。语音可以用[配音](/zh/guides/audio-3d)生成，也可以上传录音。 |
| **分镜** | 把一个创意拆成多个镜头，角色和风格保持一致，按顺序生成。打开 Agent 后，智能分镜会帮你写好每个镜头。 |

每段视频可以是 16:9、9:16、1:1、4:3、3:4 或 21:9，768p 或 1080p，时长 5、10 或 15 秒，并可选运镜预设。设置面板见[生成](/zh/guides/generate)。

<Tip>
参考生视频会严格跟着提示词走。请明确点名每张参考图（「把 `<Picture 1>` 作为产品，`<Picture 2>` 作为讲解人」），不要只是顺带提一句。参考视频会连同里面人物的长相一起被参考；想让另一个角色做别人的动作，请用 **动作控制**，它只取姿态。
</Tip>

## 编辑视频

选中视频会出现它的工具栏：

<Frame>
  <img src="/images/video-toolbar.webp" alt="生成视频上方的视频工具栏" />
</Frame>

- **视频裁剪** 打开视频编辑器：裁剪、分割成片段，设置每段的速度和音量，加淡入淡出转场和字幕，然后 **导出为新视频** 或 **替换原视频**。
- **视频延长** 从最后一帧接着往下生成，可以用提示词描述接下来发生什么。
- **放大** 到 1080p、2K 或 4K，保留音频和帧率。
- **去背景** 逐帧抠出主体，放在黑色背景上。
- **照此再画** 用同样的提示词和设置、换个种子再生成一次。

视频也可以拖进对话，作为给 Agent 的参考。预览大图里有静音开关。
