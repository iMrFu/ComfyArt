局域网里其他的 ComfyUI 也能跑 ComfyArt 的任务。结果仍会传回本机，所以画布、历史记录和 Agent 看到的和本地结果一样。

## 添加机器

1. 在另一台机器上启动 ComfyUI 时加 `--listen`，让它接受局域网连接，例如 `python main.py --listen 0.0.0.0 --port 8188`。
2. 打开设置菜单，点 **局域网实例…**。
3. 填名称（可选）、地址和端口，点 **添加**。

<Frame>
  <img src="/images/instances-dialog.webp" alt="局域网实例弹窗" style={{ maxWidth: '520px' }} />
</Frame>

每台机器会显示是否在线、队列里排着几个任务。取消勾选 **启用** 就不再往这台发任务，但保留登记。ComfyArt 只保存名称、地址和端口，从不要求也不保存任何密码或密钥。

## 选择任务在哪跑

设置菜单里的 **生成位置** 决定所有任务的默认去处：

<Frame>
  <img src="/images/settings-menu.webp" alt="设置菜单里的生成位置" style={{ maxWidth: '360px' }} />
</Frame>

| 选项 | 任务去哪 |
|---|---|
| 自动 | 排队最少、并且装齐了工作流所需节点和模型文件的机器，本机也算一台 |
| 本机 | 一律在本机 |
| 某台机器 | 一律排到这台的队列，不管它多忙 |
| Comfy Cloud | Comfy Cloud，需要在启动 ComfyUI 前设置 `COMFY_API_KEY` |

每张生成卡片可以在模型旁边的 **运行在** 里单独改。**跟随全局** 就按设置菜单走；选别的只对这张卡片生效，重新生成和 remix 它的结果时会沿用。

<Frame>
  <img src="/images/run-on.webp" alt="生成卡片上的运行在菜单" style={{ maxWidth: '500px' }} />
</Frame>

放大、去背景、橡皮擦这类工具按设置菜单的默认去处走。任务运行时，卡片上会显示是哪台机器接的。

## 自动分发怎么选机器

每个任务开始前，自动分发会向每台已启用的机器查询队列，并检查它是否有工作流里的每个节点、每个用到的模型文件。关机、连不上或缺东西的机器会被跳过。剩下的里面选队列最短的，一样短时选本机。如果没有任何机器能跑这个工作流，任务会交给本机，由 ComfyUI 报出原本的错误。

一张卡片一次出几张图（**数量** 2–4）算一个任务，只在一台机器上跑。想分到多台机器，就同时开几张卡片。

## 文件和模型

- 输入的图片、视频和音频会在排队前上传到对方的 `input/comfyart/`。
- 结果下载到本机的 `output/comfyart/`，文件名会加上机器名和任务号，例如 `image_00001_Spark-28138bd7.png`。
- 模型按文件名匹配，各台机器放在不同子目录也可以。
- **Qwen Image 2512** 用 ComfyArt Precise UNET Loader 加载，所以只能在装了 ComfyArt 的机器上跑。自动分发会跳过没装的机器；手动指定这样的机器会报「节点不存在」。
