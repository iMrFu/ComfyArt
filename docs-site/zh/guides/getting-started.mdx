## 准备

- 一套能正常运行的 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)，显卡要能跑你选的图像模型。
- 你要用的功能对应的模型文件，见[模型](/zh/guides/models)。只装 Qwen Image 2.1 就能用生成、快捷编辑、编辑文字和扩展。

## 安装

<Steps>
  <Step title="克隆到 custom_nodes">
    ```bash
    cd ComfyUI/custom_nodes
    git clone https://github.com/jtydhr88/ComfyArt
    ```
  </Step>
  <Step title="安装 Python 依赖">
    用运行 ComfyUI 的同一个 Python 环境。会装上 `pypdfium2`（上传 PDF）和 `rapidocr`（[编辑元素](/zh/guides/elements-mockups)的文字识别）。

    ```bash
    pip install -r ComfyArt/requirements.txt
    ```
  </Step>
  <Step title="重启 ComfyUI，打开 ComfyArt">
    点 ComfyUI 顶栏的 **ComfyArt** 按钮，或在浏览器里打开 [http://127.0.0.1:8188/comfyart/](http://127.0.0.1:8188/comfyart/)，会先进入[首页](/zh/guides/home)；点 **新建项目** 得到一块空白画布。

    <Frame>
      <img src="/images/comfyui-topbar.webp" alt="ComfyUI 顶栏里的 ComfyArt 按钮" />
    </Frame>
  </Step>
</Steps>

Comfy Desktop 里没有地址栏，也能用这个按钮进入。要回去时，点首页左侧栏或项目 Logo 菜单里的 **返回 ComfyUI**。

构建好的页面已经放在 `dist/` 里，使用 ComfyArt 不需要装 Node.js。只有修改了 `src/` 里的前端源码时，才需要用 `npm install && npm run build` 重新构建。

## 生成第一张图

<Frame>
  <img src="/images/canvas.webp" alt="ComfyArt 画布，选中一张图时出现工具栏" />
</Frame>

1. 点底部栏的 **图像生成**，画布上会出现一个生成卡片，下面是提示词框。
2. 描述你想要的图。图里要出现的文字用引号括起来，例如 `标题 "夏日饮品"`。
3. 选好尺寸、比例和张数，点箭头按钮。ComfyUI 生成时，卡片外圈会有进度环。
4. 选中生成结果，就会出现图片工具栏：快捷编辑、放大、去背景、橡皮工具，**⋯** 里还有更多工具。

## 项目和语言

- 每个项目对应一个网址：`/comfyart/?project=<id>`，保存在 ComfyArt 的 SQLite 数据库（`user/__comfyart/data.db`）里，并有快照历史可以恢复。见[首页与项目](/zh/guides/home)。
- 界面语言默认跟随 ComfyUI 的语言（中文或英文），随时可以在设置菜单里切换。
